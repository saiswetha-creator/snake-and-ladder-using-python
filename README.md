# 🎲 Snake and Ladder Game using Python

## Description
A beginner-friendly Snake and Ladder game developed using Python. Two players roll a dice and move across the board. Ladders move players forward, while snakes move them backward. The first player to reach 100 wins the game.

## Features
- Two-player gameplay
- Random dice rolling
- Snake and ladder movements
- Automatic player position tracking
- Winning condition

## Technologies Used
- Python
- Random Library
- Conditional Statements
- While Loop
- Dictionaries

## How to Run
1. Download or clone this repository.
2. Open `snake_ladder.py`.
3. Run the Python program.
4. Enter the player names and start playing!
